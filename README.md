# Pong Game 🏓

A Python implementation of the classic Pong Game using the `turtle` graphics module.  
Built as part of Angela Yu’s **100 Days of Code** challenge.

---

## 📖 Description
This project demonstrates:
- Using the `turtle` graphics library
- Event listeners for keyboard input
- Collision detection with paddles and walls
- Score tracking for two players

---

## 📂 Project Structure
pong-game/
│
├── main.py        # Runs the game
├── paddle.py      # Paddle class (movement)
├── ball.py        # Ball class (movement, collision)
└── scoreboard.py  # Scoreboard class (tracking scores)

Code

---

## 🎮 Features
- Two-player Pong game
- Ball bounces off walls and paddles
- Score tracking for both players
- Keyboard controls:
  - Left paddle: W (up), S (down)
  - Right paddle: Up arrow, Down arrow
